# 서가은 포트폴리오

게임 UI와 도트를 그리고, 생성 AI로 뽑은 그림을 게임에 쓸 수 있게 다듬는 일을 합니다. 그림이 게임 안에서 어색하면 Unity나 웹 화면 코드도 직접 열어 고칩니다.

## 대표 프로젝트

| 프로젝트 | 어떤 프로젝트 | 맡은 일 | 대표 작업 |
|---|---|---|---|
| **[DEVIANT](projects/deviant.md)** | Unity 2D 액션 로그라이트 (6인, 2026.10 ~ 진행 중) | 팀장, 아트 | 전투 HUD 도트 통일, 무기와 스킬 아이콘 54장 / 제작과 장착 흐름 재설계(입력 14번 → 7번) |
| **[한짝](projects/hanjjak.md)** | 웹 방치형 게임 (6인, SSAFY 특화 프로젝트 우수상) | 팀장, 디자인 총괄, 치장 제작 | 생성 AI 장비를 고정 마네킹에 입히는 파이프라인(치장 28세트 190종) / 몬스터 90종 발끝 맞춤 |
| **[AIVO](projects/aivo.md)** | 발표, 면접 연습 피드백 웹 서비스 (6인, SSAFY 공통 프로젝트 우수상) | 프론트엔드 | 면접, 폴더, 리포트 화면 구현 |

프로젝트별 페이지는 **문제 → 내 판단 → 진행 과정 → 결과와 배운 점** 순서로 썼습니다. 팀 전체 기능과 제가 맡은 일을 나눠 적었습니다.

## 작업 방식

- 그림은 게임 화면에 넣어 보고 판단합니다. 따로 볼 때 괜찮아도 게임 안에서 어색하면 다시 고칩니다.
- 고르기 전에 시안을 여러 장 나란히 놓고 비교합니다.
- AI가 다 됐다고 해도 결과 그림과 화면을 직접 확인합니다.
- 팀원이 만든 것, AI가 한 일, 제가 판단하고 고친 것을 나눠 적습니다.
